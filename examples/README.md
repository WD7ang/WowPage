# Optional AcademicPages examples

These files are retained for reference and excluded from the generated site.

- `pages/`: archive, collection, Markdown, terms, and map page examples.
- `data/`: original sample authors and comments.
- `talkmap/`: map demo and its bundled Leaflet assets.
- `icons/`: historical icon manifests, which referenced images absent from the repository.

To enable a page, copy it into `_pages/` and supply its referenced content/assets. For the map example, also copy `talkmap/` to the repository root; it expects `/talkmap/map.html`. Collection configuration and theme layouts remain available in `_config.yml`, `_layouts/`, and `_includes/`.
